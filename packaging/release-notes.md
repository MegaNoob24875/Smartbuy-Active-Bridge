## ACTIVE Control 1.0.0 · прошивка v5

BLE-геймпад → ESP32-S3 → USB Serial → Xbox 360 / XInput на Windows.
Проверено с **Smartbuy ACTIVE / SBG-300BT-KR** и **ESP32-S3 N16R8**.

### Что скачать

| Файл | Назначение |
|---|---|
| `ACTIVE-Control.exe` | Готовое приложение Windows x64; Python не нужен |
| `ACTIVE-Control-Windows-x64.zip` | EXE, краткая инструкция и лицензии зависимостей |
| `SmartbuyBridge-v5-ESP32S3-N16R8.bin` | Единая прошивка для Flash 16MB / OPI PSRAM, адрес `0x0` |

| `SHA256SUMS.txt` | Контрольные суммы файлов релиза |

### Первый запуск

1. Загрузите BIN через разъём **COM** платы: [инструкция](https://github.com/MegaNoob24875/Smartbuy-Active-Bridge/blob/main/docs/FIRMWARE.md).
2. Один раз установите официальный [ViGEmBus 1.22.0](https://github.com/nefarius/ViGEmBus/releases/tag/v1.22.0).
3. Переставьте кабель в **USB** и запустите EXE. Приложение само выберет порт.
4. Включите BLE-сопряжение геймпада, нажмите кнопку после подключения и дождитесь Xbox.

Единый BIN для первой установки сбрасывает NVS, Bluetooth-пары и настройки платы.
Для обновления существующей v5 используйте app-only по инструкции, без Erase all.

Для игры держите ACTIVE Control запущенным; крестик сворачивает его в трей.
Офлайн-игры вне Steam тоже работают при наличии поддержки XInput.
Приложение не устанавливает драйвер автоматически. EXE не подписан сертификатом.

### Возможности

Живой тест кнопок/стиков, L1/R1, оба курка, бинды 32 кнопок, мёртвые зоны,
инверсия и обмен стиками, профили JSON, сохранение в NVS платы и трей.
В v5 используется USB Serial с CRC16 вместо нестабильного HID-транспорта.
Пятиминутная проверка: 30 109 пакетов, 2 171 изменение ввода, без обрывов.

ESP32-S3 поддерживает **BLE**, а не Bluetooth Classic. Другие модели зависят
от парсера Bluepad32 и BLE-режима; совместимость со всеми геймпадами не заявляется.
Вибрация обратно на геймпад и эмуляция клавиатуры пока не реализованы.

Исходники, оформление и инструкции: [Smartbuy-Active-Bridge](https://github.com/MegaNoob24875/Smartbuy-Active-Bridge).
